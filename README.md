### | PROPRIETARY R&D: Ruggedized High-Frequency P2P Tactical Node
*Status: Final stages of R&D and Intellectual Property (IP) filing. Designed for sovereign defense applications.*

Led the full-stack architecture of a tactical P2P communication node, prioritizing extreme resilience, hardware-level security, and optimized data throughput in electromagnetically challenged environments.

* RF & Antenna Architecture: Engineered a high-throughput link operating in the UNII-3 C-Band variant. Integrated with a custom 4x4 MIMO antenna array and high-gain reflectors. Implemented active Digital Beamforming to achieve precise spatial multiplexing and signal directivity.
* Firmware & Secure Boot: Architected and compiled a custom Embedded Linux firmware from scratch. Performed kernel-level optimization and stripped unnecessary overhead to ensure determinism and microsecond-level latency.
* Tactical Cryptography: Developed and integrated military-grade payload encryption with secure boot mechanisms, ensuring zero-trust node authentication and anti-jamming capabilities.
* Power & Thermal Autonomy: Engineered an ultra-low power state machine. The system remains in a deep sleep state and is triggered via an interrupt-driven Multi-Modal Sensor Fusion matrix (Acoustic, Thermal, and Motion sensors) for immediate, event-driven wake-up.
* MIL-SPEC Equivalent Design: Modeled passive/active heat dissipation with embedded thermal sensors to prevent thermal throttling under extreme loads.

*Status: Completed. Engineered a high-precision, safety-critical automated hoisting and positioning architecture.*
